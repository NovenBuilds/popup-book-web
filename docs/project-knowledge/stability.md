## 已复现并修复的问题

1. **桥集成测试启动竞态**：健康端口响应后消息端口可能尚未开始监听，原测试立即握手会出现连接拒绝。现在握手对连接拒绝有次数上限的等待；超时仍失败。
2. **录制失败遗留视频轨道**：单元测试复现录制器构造和启动抛错后轨道停止次数为零。现在两种路径释放画布视频轨道后抛出错误，由分享流程保留图片。两个回归断言均已通过。
3. **重连沿用旧角度时间**：最小浏览器复现显示，重连但未收到新角度时仍为 stale（过期），没有进入 wait（等待首帧）。现在连接打开时重置角度时间；同一场景复验为 wait，随后新角度恢复 live（有效）。相关日志 `.run/debug-net.log` 与 `.run/debug-net-fixed.log`。
4. **浏览器测试断言时序**：消息解析完成时，界面节流刷新不一定已更新滑块禁用状态。测试分别等待连接/角度与界面结果，不删去对两者的断言。模拟消息发给当前已打开连接，避免启动看门狗重试后继续往旧连接发送。
